How it works

Seed one object on one frame, then track it across the clip.

Workflow

  1. Pick a mode in the toolstrip: pointer = manual, wand = AI-assisted (SAM3). With no object selected, drawing creates one called “object” — rename it in the panel.
  2. AI mode: click the object with + (or drag a box), then press Predict ✦ or Enter. Track ◀ N ▶ frames or the whole clip — Stop anytime.
  3. Manual mode: paint with the brush, outline with the polygon, or drag a box — saved to this frame only, and used as a SAM3 seed when you track from here. Finish an edit with ✓ Done, Enter, or Esc.
  4. Fix frames with the pointer (drag / resize / rotate) or the brush, then Export.

Manual tools

BrushPaint to add. A toolbar appears on the canvas: toggle the eraser and tap −/+ to resize — or use Alt-drag to erase and [] to resize. Leaving the brush saves the mask.
PolygonClick to outline a mask vertex by vertex · drag a vertex to move · click an edge dot to insert · Alt- or right-click a vertex to delete. Saved as a mask on leaving the tool.
BoxDrag to save a bounding box on this frame — coordinates only, never a mask. Move / resize / rotate it later with the pointer.

Keyboard

Escstop tracking / finish edit / close overlays & menus
Ctrl+ scroll zoom · + drag pan
Alt+ drag erase (brush)

A ● on an object means it's live in the tracker. After reopening a clip, seed an object again before tracking it. Boxes with an amber accent were hand-edited and won't be overwritten by tracking. Pinned (static) objects aren't tracked — their box is copied to every frame you track over.
